# okkiedarts.nl

Publieke website van OKKIE. (homepage, kinderuitleg, privacy, contact). **Geen app**: de dartapp staat op
https://martijndbesten.github.io/dartlog/ (repo MartijndBesten/dartlog).

Gegenereerd uit `MartijndBesten/dartlog` met `npm run build:site` (map `dist/`). Niet hier met de hand wijzigen;
bijwerken = opnieuw bouwen in dartlog en de inhoud van `dist/` hierheen kopiëren (zonder `_headers`).
